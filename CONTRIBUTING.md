# Contributing

## Branches

Za nove funkcionalnosti koristimo:

- `feature/naziv-funkcionalnosti`

Za ispravke:

- `bugfix/opis-greske`

## Commit poruke

Commit poruka treba da bude kratka i jasna.

Primeri:

- `Add login screen`
- `Fix database connection`
- `Update README`

## Pull Requests

Pre spajanja koda u `main` granu potrebno je:

1. Proveriti da projekat radi.
2. Proveriti da nema grešaka.
3. Napisati šta je promenjeno.
